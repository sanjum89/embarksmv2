

## Smart Response Format for Suggestion Pills

### What This Does
Each suggestion pill now carries a `responseFormat` hint that tells the AI how to respond — as an inline quiz, a visual chart, or warm readable text. The AI embeds `:::RICH_BLOCK{json}:::` markers for visual/quiz responses, and the chat parses and renders them as interactive components inline.

### Response Format Categories

| Pill | Format | Rendering |
|---|---|---|
| "Quiz me on this" | `inline_quiz` | 3-5 MCQ cards, pick answer, see result per question, final score card |
| "Show my skill gaps" / "My biggest skill gaps" | `skill_gaps_chart` | Horizontal bar chart: current vs required, color-coded by gap severity |
| "What's my learning path?" | `learning_path_visual` | Ordered step list with status badges (complete/in-progress/locked) |
| "What skills have I improved?" | `skill_gaps_chart` | Same chart but framed as progress |
| "Summarize this chapter" | `text` | Warm, concise markdown with emoji headers and key takeaways |
| "How does this relate to my role?" | `text` | Conversational markdown with bullet points |
| "Tips for this assessment" | `text` | Friendly numbered tips with encouragement |
| "Recommend next steps" | `text` | Short actionable list with warm tone |

### Rich Block JSON Schemas

```json
// inline_quiz
{
  "type": "inline_quiz",
  "data": {
    "title": "Quick Check: Professional Standards",
    "questions": [
      { "question": "What is...?", "options": ["A","B","C","D"], "correctIndex": 2, "explanation": "Because..." }
    ]
  }
}

// skill_gaps_chart  
{
  "type": "skill_gaps_chart",
  "data": {
    "title": "Your Skill Gaps",
    "skills": [
      { "name": "Client Admin", "current": 40, "required": 80, "currentLevel": "Intermediate", "requiredLevel": "Expert", "gap": "High" }
    ]
  }
}

// learning_path_visual
{
  "type": "learning_path_visual",
  "data": {
    "modules": [
      { "title": "Heritage & Values", "status": "completed", "skillTarget": "Onboarding" },
      { "title": "Client Risk", "status": "in_progress", "skillTarget": "Onboarding" }
    ]
  }
}
```
